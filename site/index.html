YayaInk.Orleans.Unions

Zero-boilerplate Microsoft Orleans serialization support for C# union types, powered by a Roslyn source generator.

Install

dotnet add package YayaInk.Orleans.Unions --version 0.1.0-preview.1
dotnet add package YayaInk.Orleans.Unions.Generators --version 0.1.0-preview.1

Usage

using YayaInk.Orleans.Unions;

[Union]
[GenerateUnionSerializer]
public union Result<T>(Ok<T>, Err);

[GenerateSerializer]
public sealed record Ok<T>([property: Id(0)] T Value);

[GenerateSerializer]
public sealed record Err([property: Id(0)] string Message);

About

YayaInk.Orleans.Unions emits Orleans IFieldCodec<T>, IDeepCopier<T>, and serializer manifest registration code for preview C# union declarations marked with [GenerateUnionSerializer].

The packages target projects using Microsoft Orleans, C# preview features, and union declarations that need to round-trip through Orleans serialization.
